# Oathsworn Might Deck Tracker

Deck stats for Oathsworn.

[Served here.](https://panditaktak.github.io/Tool-Oathsworn_Might_Deck_Tracker/)

## Issues

1. Exploding dice are modelled very simplistically -> If your deck has a load of exploding dice left and not much else, expect shennanigans....
2. Stats aren't accurate as a result of deck wrap-arounds.
